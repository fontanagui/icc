# Material original recebido

Esta pasta preserva os fontes e scripts fornecidos inicialmente, incluindo
os créditos originais. O programa é um resolvedor genérico de sistemas não
lineares com libmatheval, formato de entrada próprio e executável
`resolucaoSNL`. Não faz parte da compilação principal nem é a baseline dos
experimentos atuais.

`sist.dat` contém exemplos do formato genérico antigo. O script `broyden.sh`
desta pasta também usa o formato antigo. Para as versões atuais, utilize
`scripts/gerar_entradas.sh` a partir da raiz do projeto.
